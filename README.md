# Forest Park Route Lab

A small interactive tutorial for building running routes in the COROS app, sending them to a COROS Apex 4, and opening GPX files in other mapping software.

Static site: `index.html` plus one sample route (`white-salmon-lazy-river.gpx`). No build step.

## Run locally

Open `index.html` in a browser.

## Host on GitHub Pages

Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)`.

## Add a route

1. Put the `.gpx` file next to `index.html`.
2. Add a card or link for it in the page and point the download link at the new file.
